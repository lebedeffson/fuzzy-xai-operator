# FAST baseline resolution

The acronym `FAST` is excluded from confirmatory tables because the reviewer reference does not identify a unique method.

The likely candidate is **FXAM (Fast and eXplainable Additive Model)** from *A Unified and Fast Interpretable Model for Predictive Analytics*, arXiv:2111.08255. The paper is pinned as the semantic reference, but no official, versioned implementation with a reproducible package contract was identified for this cycle.

Therefore FXAM is recorded as `excluded_no_pinned_reproducible_implementation`; it is not silently replaced by another additive model and the name `FAST` is not used in result tables.
