# Q1 final external studies

This directory contains frozen stimuli, blinded assignment slots, consent material, response schemas and scorers.
It does not contain generated participant or reviewer responses. Recruitment is prohibited until the ethics status is
`approved` or `exempt` and an institutional record is attached.

Run `python scripts/q1_final/verify_external_gates.py --allow-open` for technical packaging. The same command without
`--allow-open` is the stable-release gate and must fail until genuine anonymized and signed records are imported.
