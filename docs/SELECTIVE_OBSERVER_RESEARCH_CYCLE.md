# FuzzyXAI two-stage selective observer

This milestone does not rewrite or relabel the frozen Q1 result. It introduces a new formative method whose eventual
confirmatory claims require new data and independent external records.

## H3 selective controller

The controller receives out-of-fold risk channels and returns `accept`, `short_review`, `full_review` or `block`.
Thresholds are selected from controller out-of-fold predictions. The confirmatory comparison reports risk-coverage
and cost-review curves rather than a single arbitrary cost.

## H5 route validity

H5a measures whether a mandatory explanation contract was violated and whether automatic certification was
prevented. H5b is a separate held-out prediction model comparing baseline confidence/calibration/shift features with
typed route features. Failure of H5b cannot erase a valid H5a result.

## H6 conditional ablation

H6a checks the ablation method on planted rules over real feature distributions. H6b selects stable,
subgroup-specific, low-redundancy rules using train/validation only and compares each candidate with at least five
matched controls on two new held-out datasets.

## External gates

Domain-language review, comprehension and expert-action studies remain open. The repository provides protocols,
schemas and scorers only. It does not create participant or expert records. A stable release remains prohibited until
the applicable preregistered gates close with real evidence.
