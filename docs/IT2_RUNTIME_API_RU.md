# FuzzyXAI IT2: использование в обычном API

IT2 интегрирован в `FuzzyXAI.wrap` как **нативная модель**, а не как пост-хок
оформление прогнозов обычной сети. Анализ сохраняет нижние и верхние степени
принадлежности, интервал логита и точечную оценку после объявленной
редукции типа. Прогноз формируется из двух концов индуцированного интервала,
вместо использования только номинальной функции принадлежности.

## Пример (только синтетический, не медицинская модель)

```python
from fuzzyxai import FuzzyXAI, IT2FuzzyLogit, IT2FeatureRule, IT2Shoulder

model = IT2FuzzyLogit(
    intercept=0.0,
    n_input_features=1,
    features=(
        IT2FeatureRule(
            feature_index=0,
            feature_name="signal",
            low_coefficient=-4,
            high_coefficient=4,
            membership=IT2Shoulder(
                left_min=0.0, left_max=0.2,
                right_min=0.6, right_max=0.8,
                nominal_left=0.1, nominal_right=0.7,
            ),
        ),
    ),
)
result = FuzzyXAI.wrap(model).explain_one(
    [0.4], object_id="demo-001",
    dataset_version="controlled-synthetic-v1",
)
print(result.action)
print(result.explain_it2())
print(result.to_dict(detail="compact")["it2_explanation"])
```

## Как интерпретировать

- **FOU / LMF, UMF:** область неопределённости степени принадлежности из
  заранее объявленного семейства функций. Это не доверительный интервал
  вероятности заболевания.
- **Type-2 midpoint:** среднее вероятностей на концах индуцированного
  интервала, фактически используемое при формировании точечного предсказания.
- **Policy:** при пересечении порога `request_more_data`; при чрезмерной
  ширине `defer_to_human`; при отсутствии `dataset_version` — `block`.
  Более строгий результат наблюдателя риска сохраняет приоритет.
- **Аудит:** в `result.prediction.metadata["it2_guard"]` находятся
  контрольные суммы, границы, решение и результат независимого пересчёта.
  Полный исходный ряд и манифест модели в публичный объект не дублируются.
  Для самостоятельного воспроизведения при доверенном экземпляре модели
  используйте `make_it2_receipt` и `verify_it2_receipt`.
- **Научный статус:** ветка включает исследовательскую апробацию на WDBC.
  Подтверждений клинической пригодности или статистического покрытия нет.

Для Type-3 нечётких множеств здесь **нет** заявленной реализации;
смешивать три уровня неопределённости без формального контрактного описания
не следует.

## Связь с главой 3: компонент неопределённости риска

По умолчанию `FuzzyXAI.wrap(IT2FuzzyLogit)` регистрирует в `ExplainPlan`
`UncertaintyPolicy(method="it2_parameter_width")`. Наблюдатель риска читает
непосредственно вычисленную ширину `probability_upper - probability_lower`;
он не подменяет её энтропией классификатора или суррогатной точностью.
Эта величина представляет *эпистемическую неопределённость параметров
нечёткой модели*, а не частотную вероятность ошибки предсказания.

Если пользователь передал собственный `explain_plan`, он остаётся
неизменным; для аналогичного поведения метод необходимо объявить явно.
В случае отсутствующего измерения полноценный риск не выдумывается.

## Контроль доверенного источника модели

Численное воспроизведение и SHA256 манифеста **не доказывают, кто обучал
модель и какие данные использовались**. Для внешне закреплённой версии
объявите в `ExplainPlan.metadata` независимый отпечаток, полученный из
реестра экспериментов или подписанного протокола обучения:

```python
from fuzzyxai import ExplainPlan, FuzzyXAI
from fuzzyxai.interval_type2 import content_sha256

plan = ExplainPlan.default()
plan.metadata["it2_expected_model_sha256"] = "<SHA256, заранее сохранённый независимо>"
fuzzy = FuzzyXAI.wrap(model, explain_plan=plan)
result = fuzzy.explain_one(
    [0.4], object_id="case", dataset_version="controlled-v1")
assert result.explain_it2()["model_anchor_status"] == "matched_declared_external_SHA256"
```

В приведённом фрагменте необходимо подставить **действительный, отдельно
зафиксированный** SHA256, а не вычислять его из только что предъявленной
модели при проверке. Если отпечаток не совпадает, вывод отклоняется. Если
независимая привязка не задана, в отчёте явно отражается статус
`in_process_model_only_no_external_authentication`.
