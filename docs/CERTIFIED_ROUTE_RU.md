# Certified Route: проверяемая композиция объяснений FuzzyXAI

Новый модуль `fuzzyxai.core.certified_route` — опциональное расширение существующей композиции `compose`. Он связывает объяснения с отдельно подписанным прогнозом, проверяет смену события, версии и источники, согласованность скалярных значений, правила и все зарегистрированные ветви графа. Возвращает `certified`, `rejected` либо `insufficient_evidence`.

## Граница доверия
Подписание через HMAC выполняет отдельный доверенный адаптер модели; наблюдатель не должен сам создавать исходную запись. Пара дополняющих событий должна быть зафиксирована внутри подписи `complement_event_id`. Установление корректной подписи не доказывает истинность исходного предсказания. Хэши идентифицируют переданные байты, а не удостоверяют происхождение байтов без доверенного адаптера.

## Верификация
```bash
python -m pip install -e '.[dev]'
python -m pytest -q -ra framework/fuzzyxai/tests/test_certified_route.py
python experiments/certified_route_demo.py --output-dir certified_route_demo
python experiments/certified_route_benchmark.py --output-dir certified_route_results
```

Тест интеграции с `fuzzyxai.selective_observer.local_effects` выполняется без `importorskip`, включая один реально обученный линейно-аддитивный sklearn-классификатор и независимые ответы модели. Протокол *не* поддерживает автоматическую верификацию произвольного SHAP/LIME или нелинейных взаимодействий. CLI JSON v1 поддерживает только скалярное представление.

## Научный статус
Разработческий эксперимент: 9 моделей, 1530 отложенных прогнозов, 19 890 взаимозависимых сценарных проверок, заранее заданные нарушения и отрицательные контроли. Сильный равнодоступный ручной контроль со всеми теми же исходными записями даёт идентичные результаты; превосходство по accuracy/F1 не показано. Это не подтверждающее внешнее испытание и не клиническая валидация.
