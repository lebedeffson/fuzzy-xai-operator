# Минимальный диагностический разрез

Разрез является минимальным по зарегистрированной стоимости множеством исправляемых
диагностических атомов, покрывающим все невыполненные обязательства маршрута.
Диагностический атом имеет точную форму:

```text
node:preprocessor/field:version/violation:contract_mismatch
edge:preprocessor-to-model/subject/violation:contract_mismatch
```

Для не более чем 28 атомов используется детерминированный branch-and-bound.
Сохраняются все найденные равностоимостные оптимальные разрезы в пределах
зарегистрированного лимита. Для больших задач применяется weighted greedy cover;
такая выдача всегда имеет `optimal=False`.

`verify_cut` независимо проверяет покрытие, стоимость, список непокрытых обязательств
и корректность отметки оптимальности. Разрез не является ни причиной ошибки модели,
ни последовательностью восстановления.
