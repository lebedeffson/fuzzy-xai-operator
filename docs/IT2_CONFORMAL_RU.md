# Split conformal + интервальная нечёткость Type-2: два независимых уровня

**IT2 FOU:** интервал `[LMF, UMF]` функции принадлежности изменяет
логит и может запретить автоматическое решение при пересечении порога.
Это НЕ статистический интервал для правильного диагноза.

**Split conformal LAC:** на отдельной *калибровочной* выборке фиксированной
модели считается `s_i = 1 - p(y_i|x_i)`. При `n` наблюдениях и
заявленном `alpha` выбирается `k = ceil((n+1)(1-alpha))`.
`q` — k-я порядковая статистика. Если `k>n`, используется бесконечный
порог, а множество всегда содержит обе метки.

Множество классов: `C(x) = {y : 1-p(y|x) <= q}`. При пустом или
двухэлементном множестве FuzzyXAI не разрешает автоматическое принятие
решения, даже если IT2 FOU-ограничение само по себе его допускает.
Более строгие существующие решения никогда не смягчаются.

## Предпосылки и пределы доказательства

Маргинальное покрытие `>=1-alpha` относится к распределению будущего
случая при **обменности** калибровочных и тестовых данных, неизменной
обученной модели и отсутствии утечек train/calibration/test.
Оно не гарантирует индивидуального, подгруппового или клинического
покрытия при сдвиге распределения. Используемый LAC может вернуть
пустое множество; это отражается как отказ от автоматического ответа.

FuzzyXAI проверяет явное разбиение по переданным идентификаторам,
арифметику квантиля и целостность манифеста. Он не способен сам доказать
факт корректного сбора данных, внешнюю подпись или соблюдение обменности.

## Использование

```python
from fuzzyxai import FuzzyXAI, ExplainPlan, IT2SplitConformal

calibration = IT2SplitConformal.fit_it2(
    model, X_calibration, y_calibration,
    calibration_ids=calibration_ids,
    training_ids=training_ids,
    calibration_dataset_version="study-validation-v1",
    alpha=0.1,
)

plan = ExplainPlan.default()
plan.metadata["it2_conformal"] = calibration.to_dict()
# При наличии независимо утверждённого SHA256:
# plan.metadata["it2_conformal_trusted_sha256"] = approved_calibration_sha

result = FuzzyXAI.wrap(model, explain_plan=plan).explain_one(
    x_test, object_id="new-test-object", dataset_version="study-test-v1",
)
print(result.explain_it2()["conformal"])
```

Указанные ID должны быть уникальными и не пересекаться; при совпадении
идентификаторов исходного объекта с обучающей/калибровочной выборкой
выполнение прекращается. Манифест содержит отсортированные
неконформные оценки и хеши идентификаторов, но не исходные матрицы:
эти оценки всё равно являются данными, которые могут быть чувствительными.
Не публикуйте реальные медицинские манифесты без проверки доступа.

Связка с IT2 — **не Type-3 и не калибровка FOU**.

## Научный протокол сравнения с Type-1

`experiments/doctoral_it2_conformal.py` воспроизводит пять разбиений
WDBC с четырьмя **непересекающимися** частями: обучающая,
конформная калибровка, отдельный набор для подбора порога автоматического
решения и финальный тест. Параметры модели и нечёткости оцениваются только
на train; конформные квантили — только на calibration; порог,
уравнивающий долю автоматических ответов Type-1 с IT2 на уровне policy,
выбирается без доступа к test. Предсказания и фактические ошибки
считаются на test один раз.

Отдельно сообщаются три контрольных варианта: обычный Type-1 с conformal,
Type-1 с дополнительным порогом для сопоставимого покрытия и
IT2 + conformal + FOU. **Фактическая** доля автоматически принятых
тестовых случаев всё равно может различаться, так как порог выбран
на независимой policy-части. Результаты описательные, не причинное
доказательство эффективности IT2. Стратификация по меткам
влияет на обменность; конформная гарантия не объявляется
доказанной для этого конкретного протокола без дополнительного анализа.
