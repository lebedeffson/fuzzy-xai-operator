# Повторная сертификация

`RouteRecertifier` сравнивает состояние до и после фактически выполненных действий и
повторно запускает весь реестр контрактов. Отчёт различает:

* `complete_recovery`;
* `partial_recovery`;
* `no_change`;
* `degraded`;
* `verification_inconclusive`.

Статус полного восстановления возможен только тогда, когда все обязательные контракты
после изменения подтверждены. Отчёт содержит разрешённые, оставшиеся и новые
нарушения, результаты каждого шага и SHA256 обоих маршрутов.

Экспериментальная инверсия mutation transaction не является рабочим восстановлением и
должна оставаться в `experiments/h10_*` или `gold_oracle`.
