# Диагностический комплекс FuzzyXAI v21

Версия `1.4.0a1` добавляет прикладной контур структурной диагностики объяснительного
маршрута. Контур отвечает за проверку зарегистрированных контрактов, локализацию
нарушения, поиск минимального диагностического разреза, план восстановления и
повторную сертификацию.

```python
from fuzzyxai import FuzzyXAI

report = FuzzyXAI().diagnose(route=route, repair_mode="plan")
print(report.summary("user"))
print(report.minimal_cut)
print(report.repair_plan)
```

## Научная граница

Диагностика проверяет структурную допустимость маршрута. Она не устанавливает
правильность прогноза, не заменяет предметную проверку и не является доказательством
повышения безопасности. Результат H10-C в предшествующем Gold-цикле остаётся
поисковым: sealed-часть не открывалась, а ручное согласование не завершено.

Старые `audit_h10` и политики сохранены для воспроизводимости. Новый пакет не меняет
результаты `v1.3.0`, v16, v18, v19 и ветки H10 final Gold.

## Стадии

1. `RouteGraphBuilder` переводит публичные маршруты в единый граф.
2. `DiagnosticValidator` проверяет узлы, рёбра и зарегистрированные контракты.
3. `DiagnosticCauseAnalyzer` строит доказательную цепочку без неподтверждённого `root cause`.
4. `MinimalDiagnosticCutFinder` решает взвешенную задачу покрытия обязательств.
5. `ActionableRepairPlanner` выбирает providers только для элементов разреза.
6. `RepairExecutor` допускает изменение только через явный execution context.
7. `RouteRecertifier` полностью перестраивает проверку после фактических изменений.
8. `DiagnosticReporter` формирует детерминированный audit trace.

Рабочий пакет не импортирует `gold_oracle`, не читает mutation log и не копирует
эталонные значения в наблюдаемые.
