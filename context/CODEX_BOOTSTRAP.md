# Codex bootstrap

At each P19 loop read `AGENTS.md` and `ACTIVE_TASK.md`. Read
`CURRENT_STATE.md` only when overall status is needed. State one hypothesis,
inspect minimal files, make one coherent change, run targeted checks, record a
compact result in `ACTIVE_TASK.md`, then continue only when the next step is
unambiguous.

Never use Git/VCS commands in this repository. Locked/scored dissertation
artifacts are read-only.
