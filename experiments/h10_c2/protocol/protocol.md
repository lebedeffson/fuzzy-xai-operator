# Протокол

Эксперимент строится от неизменяемого commit
`a8f150b1ef3b5c6041c28098a5cc90d0e8e20ae5`. Объем новой выборки вычисляется
симуляцией мощности. Development используется для выбора одного сильнейшего
baseline. Protocol-validation проверяет замороженный маршрут. Sealed-часть
открывается один раз после прохождения power, Gold, leakage и двухстороннего
ручного согласования.

Gold выводится только из журнала низкоуровневых транзакций, graph diff,
обратных операций и отдельного исчерпывающего оптимизатора.
