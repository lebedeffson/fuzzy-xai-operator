# Гипотезы H10-C2

`H10-C2a` проверяет диагностический разрез. Основной показатель равен единице
только тогда, когда результат метода принадлежит полному множеству
сертифицированных разрезов минимальной стоимости.

`H10-C2b` проверяет восстановление отдельно. Успех требует полной повторной
сертификации, отсутствия новых критических нарушений и выполнения
постусловий без доступа рабочего метода к Gold.

Результат одной гипотезы не заменяет результат другой.
