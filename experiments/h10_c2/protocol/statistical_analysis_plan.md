# План статистического анализа

Два первичных утверждения образуют одно семейство с поправкой Холма.
Сравнение парное, поскольку все методы получают одинаковые случаи.
Bootstrap выполняется на уровне `случай -> конвейер`; доверительный интервал
и значение критерия получают из одной resampling-процедуры. Лучший baseline
выбирается только по development. Дополнительные показатели не могут
компенсировать неподтвержденный основной показатель.
